# Week 6 Assignment: Times Tables, Skip Counting & Loop Hospital

### Project Files:
* **times_table.py**: Asks the user for a number and prints its times table from 1 to 10.
* **skip_counter.py**: Uses range() to print even numbers from 0 to 20 and a countdown from 10 to 0.
* **loop_hospital.py**: Fixes three buggy loops (off-by-one error, infinite loop, and misplaced accumulator).

### Theory Questions:
**What is an off-by-one error?**
An off-by-one error is a logic error where a loop or boundary condition executes one time too many or one time too few (e.g., stopping at 9 instead of 10).

**Which range() habit helps you avoid it?**
Remembering that the stop value in range(start, stop) is exclusive, and adjusting the upper bound accordingly (e.g., using range(1, 11) to include 10).
